# ⚡ Z-GOD Bypass Charging

A lightweight Android utility built by **Ritik Raushan (Z-GOD)** to enable **Bypass Charging** on rooted Android devices. It routes power directly from the charger to the motherboard during heavy gaming, preventing battery heat and extending battery lifespan.

---

## ✨ Features
* **Direct Power Routing:** Stops battery charging while plugged in and powers the device directly via AC/USB.
* **Zero Battery Heat:** Reduces thermal throttling during long gaming sessions (Free Fire MAX, BGMI, etc.).
* **Lightweight & Fast:** Ultra-small APK size (~300 KB) with zero background bloat.
* **Root Powered:** Compatible with KernelSU, KernelSU-Next, and Magisk.

---

## 📋 Requirements
* Rooted Android Device (**KernelSU / KernelSU-Next / Magisk**)
* Kernel & Charging IC support for input suspend / charging control (`input_suspend` or `charging_enabled` sysfs nodes)

---

## 📥 Download & Installation
1. Go to the [**Releases**](https://github.com/rittik55/Z-GOD-Bypass-Charging/releases) section of this repository.
2. Download the latest `.apk` file.
3. Install the APK on your device and grant **Superuser (Root)** permission when prompted.
4. Toggle **Bypass Charging** ON before launching your game.

---

## ⚠️ Disclaimer
This tool modifies kernel power supply nodes (`sysfs`). Use at your own risk. Ensure your device kernel supports charging control before use.
